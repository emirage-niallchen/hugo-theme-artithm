# 桌宠

可以点击、拖动和收起的桌宠，在浏览器里播放。

```toml
[params.pet]
enable = true
name = '桌宠'
nicknames = ['桌宠', '摸鱼中', '营业中']
```

点击猫会招手或跳跃，拖动可以换位置，聚焦后也可以使用方向键移动。点击称号会换一个称号；点 `×` 或按 Escape 收起，右下角会露出猫头，点击即可恢复。

收起状态保存在浏览器本地，位置保存在当前标签页。后台和收起时停止动画计时。手机使用更小的显示尺寸。

素材位于 `assets/images/desktop-pet.png`，1536 × 2288；每格 192 × 208，八列十一行。前九行动画帧数依次为 6、8、8、4、5、8、6、6、6，最后两行是十六个视线方向。替换图片时需保持同样的图集布局，或同时修改 `assets/js/pet.js` 中的帧定义。

设为 `enable = false` 后，模板不输出挂件、样式和脚本引用。
