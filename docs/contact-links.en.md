# Sidebar contact links

[简体中文](contact-links.md) · English

Edit `[params.contact]` in your `hugo.toml`. The links appear below the email button in the author card, in both the desktop sidebar and the mobile menu. Rebuild and redeploy your site after making changes.

## Link to a profile

Replace an empty string with your full profile URL:

```toml
[params.contact]
github = 'https://github.com/yourname'
xiaohongshu = ''
douyin = ''
zhihu = ''
bilibili = ''
wechat = { account = '', qrcode = '', note = '' }
youtube = ''
x = ''
sspai = ''
substack = ''
medium = ''
v2ex = ''
ghost = ''
```

Empty entries are hidden without leaving gaps. Update your existing configuration rather than adding a second `[params.contact]` table.

## Show an account or QR code

Use an inline table instead of a URL. Every platform supports these fields:

```toml
wechat = { account = 'Your WeChat ID or public account', qrcode = '/images/contact/wechat.png', note = 'Find me on WeChat or scan to follow' }
```

- `account`: The account ID or name, with a copy button.
- `qrcode`: A QR code image path or a full HTTPS image URL.
- `note`: A short description.
- `url`: An optional profile link in the contact card.

An account name alone is enough to show a card. A URL alone still opens directly:

```toml
xiaohongshu = { account = 'Your account', url = 'https://www.xiaohongshu.com/user/profile/your-id' }
wechat = { account = 'Your public account' }
```

Place QR code files in `static/images/contact/`. Configuration paths start with `/images/contact/`, without `static`. Use the QR code generated by the platform; no QR codes are included by default.

An entry with only `url` opens directly. Adding any of `account`, `qrcode`, or `note` opens a contact card instead. Clear all fields to hide the entry. Visitors can close a card with its close button, Escape, or a click on the backdrop. Focus then returns to the original icon.

## Icons and order

Reorder entries in `data/contact.yml` to change their display order. Icons are local SVGs with their brand colors, without requests to an external icon service. Monochrome brands such as GitHub, X, and Medium keep their original colors.

See the [icon guide](contact-icons.en.md) for sources and licenses. To enable the Ghost icon, fill in its URL.
